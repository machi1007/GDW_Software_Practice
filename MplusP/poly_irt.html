📈 多選項 IRT (Rasch / PCM / GPCM)

研究目的：當考卷不是只有「對/錯」，而是有「0分, 1分, 2分」的部分給分題（如申論題、數學計算步驟給分），或者是李克特 5 點量表時，我們需要使用 GPCM 或 PCM 來算出每個「門檻 (Threshold)」的難度。

📦 Step 1: 下載資料檔 (gpcm.dat)

資料為 3 題申論題的得分，每題可以得 0, 1, 或 2 分。

0 1 2
2 2 2
1 0 1
0 0 0
2 1 1
✅ 下載成功！

📝 Step 2: 下載語法檔 (gpcm_model.inp)

💡 統計駭客技巧：

  • 跑 GPCM：允許每題鑑別度不同（預設 `F BY q1-q3*;`）。
  • 跑 PCM / Rasch：強迫每題鑑別度一樣，語法改為 `F BY q1-q3@1;`。
TITLE: GPCM Model (Polytomous IRT);
DATA: FILE IS gpcm.dat;
VARIABLE: 
  NAMES ARE q1-q3;
  CATEGORICAL ARE q1-q3; ! 宣告為類別變數，Mplus會偵測到有3個類別(0,1,2)

MODEL:
  ABILITY BY q1-q3*; ! 潛在特質測量這3題 (GPCM 允許各題鑑別度不同)
  ABILITY@1;         ! 固定變異數為 1

OUTPUT: STANDARDIZED;
✅ 下載成功！

🏃 Step 3: GPCM 報表解讀 (門檻難度)

因為每一題有 0, 1, 2 三種分數，所以會有 兩個 Thresholds (門檻)：從 0 進步到 1 的難度，以及從 1 進步到 2 的難度。

IRT PARAMETERIZATION
                   Estimate       S.E.  Est./S.E.    P-Value
Item Discriminations (鑑別度 a)
    Q1                1.250      0.145      8.620      0.000

Item Difficulties (門檻難度 b)
    Q1       Threshold 1  -1.052     0.210     -5.009      0.000
    Q1       Threshold 2  1.840      0.315      5.841      0.000

💡 報表白話文翻譯：

  • Threshold 1 (-1.052)： 從「得 0 分」跨越到「得至少 1 分」的難度是負的。代表這題要拿到部分給分（1分）非常簡單。
  • Threshold 2 (1.840)： 從「得 1 分」跨越到「拿滿分 2 分」的難度飆高到 1.840。代表這題雖然容易拿分，但要「完全答對」需要極高的能力！
