NOVICE TO VETERAN

單維度基礎戰力 (IRT 家族進化史)

> 任務描述：在單一屬性的森林裡，怪物的機制隨著難度不斷進化，加入了運氣、失誤與非對稱護盾機制。

📌 2PL 模型：經典雙屬性怪物

怪物擁有最基礎的「防禦力」與「靈敏度」。

$$P(\theta_n) = \frac{1}{1 + \exp(-a_i(\theta_n - b_i))}$$
$\theta_n$: 你的綜合戰鬥力
$b_i$: 怪物防禦力（難度）
$a_i$: 怪物靈敏度（鑑別度）

📌 3PL 模型：加入「賽中/保底勝率」機制

怪物自帶 「瞎猜漏洞」。就算你戰力是負的，瞎揮一通也有基礎機率爆擊打贏。

$$P(\theta_n) = c_i + (1 - c_i) \frac{1}{1 + \exp(-a_i(\theta_n - b_i))}$$
$c_i$ (Guessing): 瞎猜率。曲線下限提升至 $c_i$。

📌 4PL 模型：加入「手殘/疲勞」機制

遊戲加入了 「最高勝率上限」。因為粗心或手殘，勝率永遠無法達到 100%。

$$P(\theta_n) = c_i + (u_i - c_i) \frac{1}{1 + \exp(-a_i(\theta_n - b_i))}$$
$u_i$ (Upper Asymptote): 最高勝率上限。曲線上限被壓低至 $u_i$。

📌 5PL 模型：非對稱護盾變形

怪物的勝率曲線不再是對稱的 S 型，需要一個 「非對稱參數」 來扭曲空間。

$$P(\theta_n) = c_i + (u_i - c_i) \left[ \frac{1}{1 + \exp(-a_i(\theta_n - b_i))} \right]^{v_i}$$
$v_i$ (Asymmetry): 非對稱參數。當 $v_i \neq 1$ 時，S型曲線上下半部彎曲程度不同。
ADVANCED

多維度屬性戰鬥 (MIRT & MRCMLM)

> 任務描述：怪物擁有多重弱點，你可以用力量強攻，也可以用智力巧取。

📌 Mark D. Reckase 模型 (M2PL)

$$P(\boldsymbol{\theta}_n) = \frac{\exp(\mathbf{a}_i' \boldsymbol{\theta}_n + d_i)}{1 + \exp(\mathbf{a}_i' \boldsymbol{\theta}_n + d_i)}$$
$\mathbf{a}_i'$: 怪物對各向度的「弱點向量」
$d_i$: 怪物截距（與整體容易度有關）

📌 Adams 等人的 MRCMLM 模型

嚴格計分型模型，用於部分給分的複雜題目。

$$P(X_{ni}=j | \boldsymbol{\theta}_n) = \frac{\exp(\mathbf{b}_{ij}' \boldsymbol{\theta}_n + \mathbf{a}_{ij}' \boldsymbol{\xi})}{\sum_{k=1}^{K_i} \exp(\mathbf{b}_{ik}' \boldsymbol{\theta}_n + \mathbf{a}_{ik}' \boldsymbol{\xi})}$$
$\mathbf{b}_{ij}$: 計分矩陣（開發者規定這題考什麼能力）
$\boldsymbol{\xi}$: 怪物難度參數
ELITE SECRETS

Reckase 密室：書中難解公式拆解

> 任務描述：解析 Reckase 書中最讓人頭痛的幾何參數。

🛡️ 機制一：互補性 vs 非互補性

  • 互補性 (Compensatory)： 只要一個屬性高到爆，就能補足另一個。公式特徵是能力項 相加 ($\mathbf{a}_i' \boldsymbol{\theta}$)。
  • 非互補性 (Non-Compensatory)： 每項能力都必須過關。公式特徵是 相乘 ($\prod P_k$)。

⚔️ 機制二：怪物絕對指標 (MDISC, MDIFF, Angles)

多維度鑑別度 (MDISC)：

$$MDISC_i = \sqrt{\sum_{k=1}^m a_{ik}^2}$$

解讀：怪物總體的挑人能力，利用畢氏定理算出最陡峭的總坡度。

多維度難度 (MDIFF)：

$$MDIFF_i = \frac{-d_i}{MDISC_i}$$

解讀：怪物在多維空間中距離原點的絕對直線距離，數值越大代表越難。

方向餘弦 (Angles/Directions)：

$$\cos \alpha_{ik} = \frac{a_{ik}}{MDISC_i}$$

解讀：這隻怪物偏向哪種能力？算出它偏向哪一個能力軸。

BOSS FIGHT

技能樹解鎖診斷 (傳統認知 CDM)

> 任務描述：不再看分數，而是看你「解鎖了哪些技能招式(0或1)」。

📌 DINA 模型 (AND 邏輯)

$$P(X_{ni}=1 | \boldsymbol{\alpha}_n) = (1-s_i)^{\eta_{ni}} g_i^{1-\eta_{ni}}$$

技能判定：$\eta_{ni} = \prod \alpha_{nk}^{q_{ik}}$

$\boldsymbol{\alpha}_n$: 考生的技能向量
$s_i$ (Slip): 手殘失誤率
$g_i$ (Guess): 瞎猜率

📌 GDINA 模型 (綜合 Combo)

$$P(X_{ni}=1 | \boldsymbol{\alpha}_{nl}^*) = \delta_{i0} + \sum \delta_{ik} \alpha_{nlk} + \sum \delta_{ikk'} \alpha_{nlk} \alpha_{nlk'} \dots$$
$\delta_{i0}$: 裸考勝率
$\delta_{ik}$: 習得單一技能的戰力提升
$\delta_{ikk'}$: 技能組合出的額外 Combo 傷害
🎓 DOCTORAL RESEARCH

情意測驗診斷 (Affective CDM)

> 任務描述：這不再是打怪！這是 RPG 的「NPC 陣營系統」。沒有絕對對錯，只有「性格標籤」是否產生共鳴。

📌 Q-matrix 轉念：T-matrix (Trait Matrix)

我們不再問「這題需要什麼能力？」，而是問「選這個選項的人，背後受到哪些心理特質驅動？」

📌 參數的重新詮釋 (GDINA 變形)

$\boldsymbol{\alpha}_n$ (Latent Profile): 潛在性格輪廓。不再是技能，而是「你是否擁有該性格」(0 或 1)。
$\delta_{i0}$ (Base Endorsement): 社會期許底線。完全沒這性格卻依然選擇「同意」的機率。
$\delta_{ik}$ (Trait Main Effect): 真實性格驅動力。
Slip $\rightarrow$ Concealment: 傳統的「手殘」，變成「壓抑/隱藏真實性格」。
Guess $\rightarrow$ Faking Good: 傳統的「瞎猜」，變成「社會期許的作假」。

🛡️ 系統 Bug 與開發挑戰 (口試防禦指南)

🐛 Bug 1：T-matrix 的主觀性迷霧

情意特質界線模糊，專家人工定義的矩陣極易出錯。

🔧 修補：實證資料驅動驗證

使用 Wald Test 或 G-DINA 內建的矩陣驗證演算法，讓數據校正矩陣。

🐛 Bug 2：連續變數被「強行降維」

人類性格通常是連續的常態分配，硬切成 0 和 1 會導致訊息遺失。

🔧 修補：引入高階模型 (HO-CDM)

保留總體連續能力值 $\theta$ 作為高階核心，低階維持 $\alpha$ 特徵標籤。

🐛 Bug 3：局部獨立性被嚴重破壞

情意測驗常有題組效應（例如某題喚起特定情緒干擾下一題）。

🔧 修補：Copula 函數或題組模型

加入 Copula 函數 吸收殘差相關，或使用 Testlet 聯合估計。

🐛 Bug 4：折疊效應 (Unfolding Effect)

傳統是能力越強勝率越高(Dominance)。但情意有時是「過猶不及」(Unfolding)。

🔧 修補：理想點認知診斷模型 (Ideal-Point CDM)

改用空間距離計算，距離越近（產生共鳴），選「同意」機率才越高。
