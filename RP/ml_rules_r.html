🛒 關聯規則探勘：心理與行為的「共現性」網路

研究實例：發掘學生問題行為的連鎖反應。
傳統研究中，我們可能要跑好幾個卡方檢定或邏輯斯迴歸來證明「A行為」與「B行為」有關。今天，我們把幾千筆輔導紀錄（如：作弊、霸凌、網路成癮、憂鬱、抽菸）丟進去，讓 Apriori 演算法自己把隱藏的「行為症候群套餐」端出來！

📦 Step 1: 準備行為清單 (counseling_records.csv)

每一列代表一個學生被記下的行為特徵，長度不一。這跟我們平常習慣的矩陣資料（要有固定的欄位）很不一樣，機器學習能處理這種非結構化資料！

Internet_Addiction, Truancy
Depression, Anxiety, Self_Harm, Insomnia
Smoking, Truancy, Internet_Addiction

✅ 下載成功！

📝 Step 2: R 語言執行語法 (使用 arules 套件)

這段語法會像淘金一樣，把出現頻率太低的巧合濾掉，只留下「強烈關聯」的鐵證。

# 1. 載入關聯規則套件
library(arules)
library(arulesViz)

# 2. 讀取「交易/行為」格式的資料
# format="basket" 代表把每一列當作一個學生的「行為籃子」
behaviors <- read.transactions("counseling_records.csv", format="basket", sep=",")

# 3. 執行 Apriori 演算法尋找規則
# 設定最低支持度(出現頻率) 0.1，最低信賴度(條件機率) 0.8
rules <- apriori(behaviors, parameter = list(supp = 0.1, conf = 0.8))

# 4. 依照「提升度(Lift)」排序，印出前 3 條最強的規則
inspect(sort(rules, by = "lift")[1:3])

# 5. 將行為連鎖反應畫成視覺化網路圖
plot(rules, method = "graph")
✅ 腳本已下載！

📊 Step 3: 報表解讀 (從「直覺」變成「鐵證」)

執行 inspect() 後，R 會印出如下的規則表，這是這套演算法的精華：

   lhs (前提條件)              rhs (後果)      support  confidence   lift
1  {Depression, Anxiety}   => {Insomnia}        0.15     0.90        3.1
2  {Truancy, Smoking}      => {Internet_Add.}   0.12     0.85        2.4

💡 報表白話文翻譯：

  • {前提} => {後果}： 第一行代表「如果一個學生同時有【憂鬱】與【焦慮】，那他也會有【失眠】」。
  • Support (支持度 = 0.15)： 代表這種「憂鬱+焦慮+失眠」的套餐組合，佔了全校輔導個案的 15%。
  • Confidence (信賴度 = 0.90)： 這是一個條件機率！意思是，一旦學生被發現有「憂鬱+焦慮」，他有 高達 90% 的機率正在經歷「失眠」。
  • Lift (提升度 = 3.1)： 這也是最重要的一項指標！如果 Lift 大於 1，代表兩者是正相關。Lift = 3.1 意味著：比起一般學生，有憂鬱與焦慮的學生，發生失眠的機率是平常人的 3.1 倍！

🔥 心理學應用價值：
這對於「預防性輔導」價值連城！當導師通報某學生有【逃學(Truancy)】與【抽菸(Smoking)】的行為時，輔導老師可以根據第二條規則（信賴度 85%），立刻警覺並介入調查該學生是否有嚴重的【網路成癮(Internet_Addiction)】問題，搶在事態惡化前進行干預。
