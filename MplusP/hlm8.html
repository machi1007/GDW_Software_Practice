🏢 Level 8: 多層次潛在類別分析 (Multilevel LCA, MLCA)

🧠 原理與應用 (Principle & Application)

1. 為什麼要做「多層次」的潛在類別分析？

傳統的潛在類別分析 (LCA) 是用來將個體「分類」的（例如：根據學生的作答行為，將他們分為「認真型」與「放棄型」）。但學生是嵌套在班級中的。MLCA 允許我們不僅對學生分類，還對「班級」進行分類（例如：這個班級是屬於「高學習風氣班」還是「低學習風氣班」）。

2. 核心機制：跨層次的機率預測 (CW ON CB)

在參數化的 MLCA 中（Mplus 宣告為 CLASSES = CB(2) CW(2)），我們定義了 Level 2 的潛在類別 (CB) 以及 Level 1 的潛在類別 (CW)。模型最精華的地方在於：它能計算出「當一個學生身處於特定類型的班級時，他落入特定學生類型的機率有多大？」這完美捕捉了「微觀個體」與「宏觀環境」的互動關係。

3. 應用何處？

MLCA 專門用於處理具有「群體特徵」與「異質性次群體 (Heterogeneous Subgroups)」的研究：

  • 教育研究 (如本例)：根據學生的行為指標 (u1-u3) 找出學生類型，並驗證「班級類型」是否會大幅改變學生的歸屬機率（例如：在高風氣班級裡，出現放棄型學生的機率極低）。
  • 行銷與商業分析：消費者 (Level 1) 嵌套於分店 (Level 2)。根據購買行為將消費者分群，並將分店分群，探討「哪種類型的分店，最容易吸引到『高消費潛力型』的顧客？」
  • 流行病學：居民嵌套於社區。探討社區的整體發展型態 (L2類別) 如何影響居民的健康風險生活型態 (L1類別)。

📊 模型概念與路徑圖 (Path Diagram)

這張圖展示了 MLCA (非參數/雙層次潛在類別) 的架構。注意：觀察變項 (矩形) 只有在第一層，第二層是透過第一層的組成結構「反向分類」出來的班級類型。

矩形：我們收集到的類別型變數 (u1-u3，例如 0=否, 1=是)。
虛線圓形：代表「潛在類別 (Latent Class)」。CW 將學生分群，CB 將班級分群。
紅實線箭頭 (ON)：跨層次預測。代表「班級的類型 (CB)」預測了「該班學生的分類歸屬機率 (CW)」。

研究目的實作：我們收集了學生的三種上課行為指標 (u1, u2, u3；1=有此行為, 0=無)。我們假設學生可以分為 2 類 (CW=2)，班級也可以分為 2 類 (CB=2)，並檢視這兩者的關聯性。

📝 Step 2: 語法檔核心 (hlm8_mlca.inp)

注意這兩大關鍵字：CATEGORICAL ARE 以及 CLASSES = CB(2) CW(2);

TITLE: Multilevel Latent Class Analysis (MLCA);
DATA: FILE IS hlm8data.dat;
VARIABLE: 
  NAMES ARE class_id u1 u2 u3;
  USEVARIABLES ARE class_id u1 u2 u3;
  CATEGORICAL ARE u1 u2 u3; ! 【極重要】宣告這些為類別變項
  CLUSTER IS class_id;  
  
  ! 宣告兩個層次的潛在類別數量
  ! CB: Class Between (班級層次分為2類)
  ! CW: Class Within (學生層次分為2類)
  CLASSES = CB(2) CW(2); 

ANALYSIS: 
  TYPE IS TWOLEVEL MIXTURE; ! 結合多層次(TWOLEVEL)與混合模型(MIXTURE)

MODEL:
  %WITHIN%
  %OVERALL%
  ! Mplus 會自動使用 CW 來解釋 u1, u2, u3
  
  %BETWEEN%
  %OVERALL%
  CW ON CB; ! 班級的類型(CB)會影響班上學生屬於哪種類型(CW)的機率

OUTPUT: TECH1 TECH8;
✅ 下載成功！

🏃 Step 3: MLCA 報表解讀重點

在 MLCA 的報表中，最精彩的部分是 LATENT CLASS PREVALENCE（潛在類別的分佈比例），尤其是條件機率的部分：

LATENT CLASS PREVALENCE
  (Between-Level Classes)
  CB = 1:                      0.650
  CB = 2:                      0.350

WITHIN LEVEL - LATENT CLASS PREVALENCE
(Conditional on Between-Level Classes)

  When CB = 1:
    CW = 1:                    0.850
    CW = 2:                    0.150

  When CB = 2:
    CW = 1:                    0.100
    CW = 2:                    0.900

💡 報表白話文翻譯：

1. CB 的整體分佈比例

首先，Mplus 將所有班級分成了兩類：CB=1 (佔全部班級的 65%) 以及 CB=2 (佔全部班級的 35%)。

2. 跨層次條件機率 (CW ON CB 的影響力)

這段報表揭示了微觀與宏觀的關聯！假設我們從其他的圖表得知 CW=1 代表「認真型學生」，CW=2 代表「放棄型學生」：

  • 當一個班級屬於 CB=1 (優良學習風氣班) 時，該班學生屬於「認真型(CW=1)」的機率高達 85%。
  • 但當一個班級屬於 CB=2 (低迷學習風氣班) 時，該班學生屬於「認真型(CW=1)」的機率瞬間掉到只有 10%，反而有 90% 的機率會成為「放棄型(CW=2)」。

結論：這份報表強烈證明了「班級的潛在類型 (CB)」對於「學生的潛在歸屬 (CW)」具有決定性的影響力，這就是多層次 LCA 最迷人的地方！
