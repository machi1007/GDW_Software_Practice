🏢 Level 8: 多層次潛在類別分析 (MLCA)

研究目的：根據學生的 3 題學習行為 (u1-u3，作答為 0 或 1)，我們想在「學生層次 (CW)」分出 2 種學習型態的學生；同時，在「班級層次 (CB)」根據這兩種學生的組成比例，分出 2 種不同風氣的班級。

📦 Step 1: 下載資料檔 (hlm8data.dat)

1 1 0 1
1 0 1 1

2 0 1 0
2 0 0 0
✅ 下載成功！

📝 Step 2: 語法檔核心 (hlm8_mlca.inp)

TITLE: Multilevel LCA;
DATA: FILE IS hlm8data.dat;
VARIABLE: 
  NAMES ARE class_id u1 u2 u3;
  USEVARIABLES ARE u1 u2 u3;
  CATEGORICAL ARE u1 u2 u3; ! 宣告為類別變項
  CLUSTER IS class_id;  
  
  ! 宣告兩個層次的潛在類別數量
  ! CB: Class Between (班級層次分為2類)
  ! CW: Class Within (學生層次分為2類)
  CLASSES = CB(2) CW(2); 

ANALYSIS: 
  TYPE IS TWOLEVEL MIXTURE; ! 結合多層次與混合模型

MODEL:
  %WITHIN%
  %OVERALL%
  
  %BETWEEN%
  %OVERALL%
  CW ON CB; ! 班級的類型(CB)會影響班上學生屬於哪種類型(CW)的機率
✅ 下載成功！

🏃 Step 3: 核心觀念解析

在一般 LCA 中，我們只分類學生；但在 MLCA 中，Mplus 會算出一個「跨層次的條件機率」。例如：
假設 CB 類別 1 是「積極型班級」，CW 類別 1 是「認真型學生」。報表會告訴我們：如果這個班級屬於「積極型班級」，那麼裡面的學生有多大的機率會是「認真型學生」？這讓我們能精準描繪「環境 (班級)」如何影響「個體特質分布」。
