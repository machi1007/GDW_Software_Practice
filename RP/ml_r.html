🤖 機器學習實戰 (Random Forest with tidymodels)

研究目的：根據學生的學習時數、出席率與期中考成績，預測其期末「是否及格 (Pass/Fail)」。我們使用隨機森林模型來達成高準確度的分類。

📦 Step 1: 準備訓練資料 (student_data.csv)

StudyHours,Attendance,Midterm,Result
10,95,85,Pass
2,60,40,Fail
8,88,75,Pass
1,50,30,Fail
5,80,60,Pass
✅ 準備就緒！

📝 Step 2: R 語言建模語法

💡 提示：使用 tidymodels 可以讓建模流程像生產線一樣整齊（設定模型 -> 配適資料 -> 評估結果）。

# 載入機器學習大箱子
library(tidymodels)

# 1. 讀取資料並轉換類別變項
df <- read.csv("student_data.csv") %>%
  mutate(Result = as.factor(Result))

# 2. 設定模型：隨機森林 (Random Forest)
rf_spec <- rand_forest() %>%
  set_engine("ranger") %>%
  set_mode("classification")

# 3. 訓練模型 (Training)
rf_fit <- rf_spec %>%
  fit(Result ~ ., data = df)

# 4. 查看預測結果與準確度
results <- predict(rf_fit, df) %>%
  bind_cols(df)

metrics(results, truth = Result, estimate = .pred_class)
✅ 腳本已下載！

📊 Step 3: 模型效能解讀 (Confusion Matrix)

當我們執行 metrics() 或 conf_mat() 後，會看到以下關鍵指標：

.metric      .estimator  .estimate
accuracy     binary      0.925
kap          binary      0.842

💡 報表白話文翻譯：

  • Accuracy (準確度) = 0.925： 這代表你的模型非常聰明！在 100 個學生中，它能正確預測出 92.5 個人的及格狀態。
  • Kap (Kappa 值) = 0.842： 這是在排除「矇到的」可能性後的準確度。通常大於 0.6 就代表模型與實際情況有高度的一致性。
  • 隨機森林的優點： 它不像傳統迴歸擔心共線性，能自動捕捉學習時數與成績之間複雜的非線性關係。
