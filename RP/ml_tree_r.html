🌳 機器學習到底在幹嘛？從「決策樹」秒懂

研究實例：預測學生輟學風險 (Dropout)。
身為教育心理學家，比起一堆看不懂的參數，您更希望電腦能給出一套「具體的輔導規則」。決策樹會自動幫我們找出「最能區分學生是否輟學的切點」。

📝 R 語言執行語法 (使用 rpart 套件)

這次我們不用複雜的框架，直接用最經典的 rpart 套件，它會直接畫出一棵樹！

# 1. 載入決策樹與繪圖套件
library(rpart)
library(rpart.plot)

# 2. 假設我們有一筆學生資料 (df)
# 變項包含：Absence(缺課天數), QuizScore(小考平均), SES(社經地位)
# 目標變項：Dropout (是否輟學：Yes / No)

# 3. 讓機器學習「自動尋找規則」
tree_model <- rpart(
  Dropout ~ Absence + QuizScore + SES, 
  data = df, 
  method = "class" # class 代表我們要分類 (Yes/No)
)

# 4. 把機器學習的結果「畫成流程圖」
rpart.plot(tree_model, type = 3, extra = 106)

📊 報表解讀 (決策樹流程圖的白話翻譯)

執行畫圖程式碼後，R Studio 會在右下角顯示一張像「倒立樹枝」的流程圖。機器學習告訴我們以下規則：

💡 機器學習找出的「輔導過濾網」：

  1. 第一關過濾 (最重要的變數)：缺課天數 (Absence)
    電腦發現，區分學生會不會輟學，最關鍵的是缺課天數。
    • 如果 Absence >= 10天 ➡️ 機器預測：高風險輟學 (Yes)。
    • 如果 Absence < 10天 ➡️ 進入下一關評估。

  2. 第二關過濾：小考平均 (QuizScore)
    對於缺課少於10天的學生，電腦發現成績是下一個關鍵。
    • 如果 QuizScore < 60分 ➡️ 機器預測：輟學 (Yes)。
    • 如果 QuizScore >= 60分 ➡️ 機器預測：安全留下 (No)。

🔥 這就是機器學習的魅力：
您不用自己去跑迴歸看 p 值，演算法「自動」在幾萬筆資料中，幫您找到了 10天 和 60分 這兩個最佳切割點！學校主任只要拿著這個規則去篩選名單，就能精準揪出需要輔導的學生，這就是「預測」的價值。
