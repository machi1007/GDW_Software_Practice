🔥 進階機器學習：XGBoost 與超參數調校

研究目的：除了建立模型，我們還要讓模型發揮極限！這次我們使用 XGBoost 演算法，並透過「10 折交叉驗證」來尋找最佳的樹木數量（trees）與學習率（learn_rate）。

📦 Step 1: 概念準備

這次我們直接使用 R 內建或先前的 student_data.csv，重點放在語法的升級。在執行此語法前，請確保您已安裝 xgboost 套件。

📝 Step 2: 進階 R 語言建模語法 (Grid Search)

💡 提示：在 tidymodels 中，如果我們不知道某個參數設定多少最好，可以寫上 tune()，讓電腦自己去「試錯」尋找最佳解。

library(tidymodels)

# 1. 切割資料與設定交叉驗證 (Cross-Validation)
set.seed(123)
# 假設 df 是我們的學生資料
# 建立 10 折交叉驗證的樣本
cv_folds <- vfold_cv(df, v = 10) 

# 2. 設定 XGBoost 模型，並將參數設為 tune() 待調校
xgb_spec <- boost_tree(
  trees = tune(),       # 讓電腦找最佳樹的數量
  learn_rate = tune()   # 讓電腦找最佳學習率
) %>%
  set_engine("xgboost") %>%
  set_mode("classification")

# 3. 設定參數嘗試的網格 (Grid)
xgb_grid <- grid_regular(
  trees(range = c(50, 500)),
  learn_rate(range = c(-3, -1)), 
  levels = 5
)

# 4. 開始尋找最佳參數 (這步會跑比較久)
tune_res <- tune_grid(
  xgb_spec,
  Result ~ .,
  resamples = cv_folds,
  grid = xgb_grid
)

# 5. 印出表現最好的前五名參數組合
show_best(tune_res, metric = "accuracy")
✅ 腳本已下載！

📊 Step 3: 模型效能與參數解讀

執行 show_best() 後，R Console 會印出如下的表格，告訴你哪種組合的準確率最高：

 trees  learn_rate  .metric   .estimator  mean (準確度)
   275       0.01  accuracy       binary          0.965
   162       0.01  accuracy       binary          0.952
   500       0.10  accuracy       binary          0.948

💡 報表白話文翻譯：

  • 超參數調校 (Hyperparameter Tuning)： 就像是買了一台高級音響，tune() 就是讓電腦自動幫你轉動「高音」和「低音」的旋鈕，試聽哪一種組合音質最好。
  • 最佳組合： 表格第一行顯示，當我們種了 275 棵樹，且學習率設定為 0.01 時，模型在未知的資料上達到了 96.5% 的最高準確度。
  • 為什麼要交叉驗證 (CV)？ 為了避免模型「死背考古題（過度配適 Overfitting）」。10 折交叉驗證就像是給模型舉辦了 10 次模擬考，每次都拿不同的題目來測驗它，確保它的 96.5% 是真正的實力！
