📝 文字探勘：讓學生的回饋「說話」 零套件無敵版

研究實例：分析學生的心理回饋與學習動機。
在資料科學中，有時候最簡單的工具最有效！為了徹底告別「套件不相容」與「版本更新」的惡夢，本篇教學將採用 100% R 語言內建語法 (Base R)。不需要安裝任何外部套件，保證隨插即用、一鍵出圖。

📝 執行語法：極簡的暴力美學

我們將模擬已經初步加入空格的文字資料，利用內建的 strsplit 進行切割，再用 barplot 畫出高頻詞彙。

# ==========================================
# 零套件文字探勘 (永遠不會報錯的 Base R)
# ==========================================

# 1. 建立「已初步斷詞」的學生回饋資料 (使用空格分隔)
feedback_data <- c(
  "老師 教得 很好 內容 充實 喜歡",
  "壓力 大 作業 太多 挫折",
  "課程 有趣 同儕 互動 多 學到 東西",
  "聽不懂 太難 老師 講太快 想 放棄",
  "未來 幫助 老師 希望 多 開 課",
  "有趣 喜歡 互動 充實 幫助",
  "壓力 挫折 放棄 太難"
)

# 2. 進行文字切割與整理
# unlist: 將切割後的文字攤平成單一長條清單
all_words <- unlist(strsplit(feedback_data, " "))

# 3. 排除雜訊
# 過濾掉只有 1 個字的無意義詞 (例如：大、多、想、課)
valid_words <- all_words[nchar(all_words) > 1]

# 4. 計算詞彙出現頻率並排序
word_freq <- table(valid_words)
word_freq <- sort(word_freq, decreasing = TRUE)

# 印出前 5 名高頻關鍵字看看結果
print(head(word_freq, 5))

# 5. 繪製精美的長條圖
# 自動判斷系統：如果是 Windows 就用微軟正黑體，避免中文變成方塊亂碼
if(.Platform$OS.type == "windows") { par(family = "Microsoft JhengHei") }

# 取前 8 名詞彙作圖
barplot(
  word_freq[1:8], 
  col = "#3f51b5",         # 使用質感的靛藍色
  border = NA,             # 移除長條圖黑框，更加現代感
  main = "學生期末回饋：高頻關鍵字分析", 
  ylab = "出現次數",
  las = 2,                 # 標籤垂直顯示，避免字體重疊
  cex.names = 0.9          # 微調底部字體大小
)
✅ 下載成功！直接貼進 R 執行吧！

📊 報表解讀：從文字看見心理狀態

💡 診斷結果分析：

  • 正向動機指標： 「老師」、「有趣」、「充實」 位居高位。這代表該課程的核心吸引力在於教師本人的魅力與互動式教學。
  • 負向壓力警報： 排行榜中也出現了 「壓力」、「挫折」、「太難」。
  • 教育心理學上的建議： 數據顯示學生的反應呈現「雙峰現象」（極度喜歡 vs. 極度挫折）。建議授課教師在維持有趣的互動之餘，需特別留意低成就學生的認知負荷，並考慮提供額外的補救教學。
