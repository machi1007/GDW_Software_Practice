🧠 認知診斷模型 (CDM: DINA Model)

研究目的：不只是給分數，我們要診斷學生是否掌握了特定的「屬性 (Attributes)」。例如：加法、減法、乘法。

📝 R 語言執行語法 (使用 GDINA 套件)

library(GDINA)

# 1. 準備反應資料 (dat) 與 Q-matrix (Q)
# 假設有 5 題，測量 3 個屬性
dat <- my_response_data
Q <- my_q_matrix

# 2. 估計 DINA 模型
mod_dina <- GDINA(dat = dat, Q = Q, model = "DINA")

# 3. 查看題目參數 (估計 Guessing 與 Slipping)
itemparm(mod_dina)

# 4. 取得學生屬性掌握機率
person_estimates <- personparm(mod_dina)

📊 報表解讀 (題目參數)

       guessing    slipping
Item 1   0.120       0.050
Item 2   0.250       0.110

💡 報表白話文翻譯：

  • Guessing (猜測度)： 指「沒掌握屬性」卻答對的機率。Item 1 是 0.12，代表學生不會也能矇對的機率很低，題目品質不錯！
  • Slipping (失誤度)： 指「掌握了屬性」卻答錯的機率。如果數值太高 (如 > 0.2)，代表題目可能有陷阱或語意不清。
  • 診斷價值： CDM 的精隨在於透過 Q-matrix，我們可以告訴老師：這個學生「加法」OK，但「乘法」還需要加強。
